# Digital Library Management System

## Project Overview
The Digital Library Management System is a web-based application developed using Java Spring Boot and Oracle Database. It helps manage books and their issuing through a simple user interface.

## Features
- User Login
- Add New Books
- View Available Books
- Search Books
- Issue Books
- Store book and issue details in Oracle Database

## Technologies Used
- Java 17
- Spring Boot
- JDBC
- Oracle Database 11g XE
- HTML
- CSS
- JavaScript
- Maven

## Project Structure
- `src/main/java` – Java source code
- `src/main/resources/static` – Frontend HTML files
- `application.properties` – Application configuration
- `pom.xml` – Maven dependencies

## How to Run the Project

1. Install Java 17 and Oracle Database.
2. Configure your Oracle database credentials using environment variables:
   - `DB_USERNAME`
   - `DB_PASSWORD`
3. Open the project folder in a terminal.
4. Run:

   `mvnw.cmd spring-boot:run`

5. Open your browser and visit:

   `http://localhost:8084/`
